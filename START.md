# AL-STYLE: публикуем свои проекты

Коллеги, запускаем пилот: свои веб-проекты теперь можно публиковать через Codex или Claude Code. Агент подготовит компьютер, установит недостающие Git и Python, загрузит проект в приватный GitHub компании и запустит его на нашем сервере через Coolify.

## 1. Установите скилл

Откройте проект в **Codex или Claude Code с доступом к локальному терминалу** и отправьте в чат:

```text
Установи или обнови скилл al-style-deploy из https://github.com/alstyle-vibecoding/al-style-deploy по инструкции README. Затем прочитай установленный SKILL.md и подготовь компьютер, автоматически установив недостающие Git и Python.
```

Если ОС попросит подтверждение установки, подтвердите его в системном окне. Пароль компьютера в чат не отправляйте. Если скилл не появился, перезапустите сессию агента.

## 2. Получите личное приглашение

Для первого деплоя запросите приглашение у **Данила или Никиты**. Оно индивидуальное, действует сутки и используется один раз. Агент подготовит интерактивный терминал входа — введите приглашение там приватно. Не публикуйте его в рабочей группе или чате с агентом.

Установка скилла доступна без аккаунта GitHub. Для деплоя нужна личная авторизация; общие пароли от сервера и Coolify сотрудникам передавать не нужно.

## 3. Опубликуйте проект

Напишите агенту:

```text
Используй al-style-deploy и опубликуй мой текущий проект. Сначала спроси меня, как назвать проект и какой адрес выбрать. Проверь запуск и дай рабочую ссылку на приложение и ссылку на админку, если она есть.
```

Агент задаст два вопроса:

- **Как назвать проект?** Например, «Каталог товаров». Название может быть на русском.
- **Какой адрес выбрать?** Например, `catalog.89.126.193.220.sslip.io`. Короткая часть `catalog` должна начинаться с латинской буквы; дальше можно использовать латинские буквы, цифры и одиночные дефисы.

Можно ответить сразу: «Название — Каталог товаров, адрес — catalog». Агент уточнит полную ссылку и проверит, свободна ли она. Если адрес занят, выберите другой.

Сейчас проекты получают адреса в зоне `89.126.193.220.sslip.io`. Это доступная зона для пилота. Для адресов вида `catalog.server.al-style.kz` или другого собственного домена сначала обратитесь к Данилу: нужна настройка DNS. Само поле домена в Coolify не регистрирует домен и не создаёт DNS-запись.

Агент подготовит настройки проекта, выполнит сборку и дождётся проверки запуска. Получите ссылку только после подтверждённого успешного деплоя. Если у приложения есть админка, агент проверит её адрес и способ входа. Скилл сам по себе не добавляет админку в приложение.

До публикации агент добавит и запустит автотесты для основных сценариев, проверит ошибки и ограничения ресурсов. Исправления должны быть небольшими: без смены дизайна, функций или технологии проекта. Тесты выполняются повторно на удалённой сборке; при ошибке новая версия не публикуется. У каждого проекта есть ограничения памяти, CPU, процессов и логов.

Ключи, пароли и другие приватные значения агент вынесет из исходников и передаст в переменные окружения приложения через защищённое хранилище. Локальная защищённая копия остаётся вне проекта. Эти значения не должны попасть в Git, сборочные файлы или сообщения чата. Если ключ уже был опубликован раньше, потребуется его заменить: удаление строки из новой версии не отменяет прежнюю утечку.

Если проект хранит рабочие записи в SQLite, JSON или CSV, агент подготовит отдельную PostgreSQL-базу и перенос данных. Существующую серверную базу он сохранит. Фотографии чеков, документы и другие загрузки разместит в постоянных томах; исходные данные сначала сохранит приватно вне проекта. Рабочие записи и загрузки не должны попадать в Git или образ приложения. После переноса агент проверит количество записей, важные суммы и файлы, а затем проверит их сохранность после обновления контейнера. Постоянные тома защищают при обновлении приложения; регулярные резервные копии за пределами сервера настраиваются отдельно.

## 4. Обновления

После изменений кода попросите:

```text
Используй al-style-deploy, обнови опубликованную версию этого проекта и проверь, что приложение работает.
```

При обновлении проекта сохраняются его репозиторий, название и адрес. Повторно выбирать их не нужно. Переименование или перенос на другой домен в пилоте согласуйте с Данилом.

Чтобы обновить **сам скилл**, повторите фразу из шага 1. Авторизация сохраняется. Изменения в GitHub не устанавливаются на компьютеры автоматически.

## Если что-то не получилось

Попросите агента проверить статус и логи деплоя и исправить конкретную ошибку. Если нужен доступ — обратитесь к Данилу или Никите. Если нужны DNS или дополнительная мощность сервера — обратитесь к Данилу. У сервера ограниченные ресурсы, поэтому агент может сообщить, что места для нового проекта пока нет.

Не добавляйте в исходники пароли, токены, `.env`, ключи и выгрузки баз данных. Значения, необходимые приложению, передаются через приватный ввод секретов, который подготовит агент.

Скилл рассчитан на веб-проекты, которые можно собрать и запустить в Linux-контейнере. Сборка проходит удалённо: устанавливать Docker на свой компьютер для публикации не требуется.

Скилл и инструкция по установке: [GitHub AL-STYLE Deploy](https://github.com/alstyle-vibecoding/al-style-deploy).
