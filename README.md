# AL-STYLE Deploy

Публикация проектов сотрудников через Codex или Claude Code: скилл готовит компьютер, устанавливает недостающие Git/Python, загружает проект в отдельный приватный GitHub-репозиторий компании и запускает его в Coolify.

## Одна фраза для сотрудника

Скопируйте в чат **Codex или Claude Code с доступом к локальному терминалу**:

```text
Установи или обнови скилл al-style-deploy из https://github.com/alstyle-vibecoding/al-style-deploy по инструкции README для моего агента. Затем прочитай установленный SKILL.md и подготовь компьютер, автоматически установив недостающие Git и Python.
```

После установки:

```text
Используй al-style-deploy и опубликуй мой текущий проект. Проверь, что он работает, и дай адрес приложения и админки, если она есть.
```

При первом деплое нужно личное приглашение от администратора AL-STYLE. Введите его приватно в терминале входа, который откроет агент. Не отправляйте приглашение или пароли в чат. Скачивание скилла не даёт права деплоить без приглашения.

## Инструкция агенту: установка и обновление

1. Определи текущую среду и агента: Codex → `codex`, Claude Code → `claude`. Используй его личный каталог скиллов: `~/.agents/skills/al-style-deploy` либо `~/.claude/skills/al-style-deploy` (на Windows — в профиле пользователя).
2. Скачай по HTTPS текущий [install.sh](https://raw.githubusercontent.com/alstyle-vibecoding/al-style-deploy/main/install.sh) для macOS/Linux/WSL или [install.ps1](https://raw.githubusercontent.com/alstyle-vibecoding/al-style-deploy/main/install.ps1) для native Windows во временный файл. Прочитай установщик, затем запусти его для текущего агента. Git и Python для этого не нужны.
3. macOS/Linux/WSL: `sh "<временный файл>" --agent codex` (или `--agent claude`). Windows: `powershell.exe -NoProfile -File "<временный файл>.ps1" -Agent codex` (или `-Agent claude`, допустим `pwsh`). Установщик разрешает `main` в конкретный commit, проверяет SHA-256 файлов и только затем заменяет скилл. Сохраняет предыдущую версию в `.al-style-deploy-backups` внутри `~/.agents/` или `~/.claude/`, вне каталога загрузки скиллов; авторизация и проекты в `~/.al-style-deploy` остаются на месте.
4. На Windows при обычной политике по умолчанию `Restricted` и отсутствии заданных корпоративных/пользовательских политик разрешён новый процесс с `-ExecutionPolicy RemoteSigned`. При необходимости разблокируй только прочитанный доверенный `.ps1`. Соблюдай ограничения компании; не используй `Bypass` и не меняй глобальную политику. [Подробности подготовки](skills/al-style-deploy/references/setup.md).
5. Прочитай установленный `SKILL.md` и выполни его `scripts/run.sh --setup-only` или `scripts/run.ps1 -SetupOnly`. Эти запускатели проверяют Git/Python и устанавливают недостающее. Подтверждение ОС или пароль администратора сотрудник вводит приватно в системном окне. Не заявляй, что подготовка завершена, пока проверка не прошла.
6. Скилл доступен на следующем ходе агента; если не появился — перезапусти сессию. После обновления используй именно новый `SKILL.md`.

Повторите первую фразу, чтобы обновить установленную копию из GitHub. Изменения в репозитории не устанавливаются на компьютеры сами по себе.

Для Codex с уже установленным Python также подходит штатный `$skill-installer` и путь `https://github.com/alstyle-vibecoding/al-style-deploy/tree/main/skills/al-style-deploy`; для обновлений используйте наш установщик, поскольку штатный отказывается заменять существующий каталог.

## Что опубликовано

Только скилл, его клиент, установщики и инструкции. Проекты сотрудников хранятся в приватных репозиториях компании. Учётные данные серверов, GitHub App, Coolify и сотрудников в этом репозитории отсутствуют.

Поддерживаются проекты с рабочим Linux Dockerfile и HTTP-сервисом. Скилл проверяет реальный результат запуска и возвращает адрес приложения. Ссылка на админку появляется только если админка реализована в самом приложении.

Каталоги скиллов: [Codex](https://learn.chatgpt.com/docs/build-skills), [Claude Code](https://code.claude.com/docs/en/skills).
